Five-minute demonstration
  1. Save a note. Watch one activity appear, then retry the same request. The count stays unchanged.
  2. Start viewing. Wait a few seconds and end the view. A DocumentViewed row displays the server-measured duration.
  3. Pause the worker and save two different notes. Notes return immediately; queued items stay Pending.
  4. Arm “Fail next item once”, then resume. The failed item remains visible, retries, and creates exactly one activity.
  5. Test tenant isolation: accessing the other tenant’s case returns 404. Switch to Bob to see a separate timeline.
  6. To demonstrate restart recovery, pause, save a note, stop and restart the API. The durable queue resumes processing.
Take-home scope: one API, one SQLite database, one background worker. Demo authentication is intentionally restricted to Development / Testing.
